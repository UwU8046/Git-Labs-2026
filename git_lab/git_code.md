- Убедились, что изменение было отменено

### Задание 8: Работа с индексом

- Изменение удалено из индекса (`git restore --staged notes.txt`)
- Снова выполнен `git status`
- **Ответ**: само изменение файла **не** было удалено — оно осталось в рабочем каталоге

### Задание 9: Отмена коммита

- Просмотрена история
- **Ответ**: отменённый коммит **не** исчез из истории. `git revert` создаёт новый коммит, который отменяет изменения предыдущего
